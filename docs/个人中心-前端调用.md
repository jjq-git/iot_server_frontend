## 用户信息

### GET /api/v1/users/me
- **权限**：已认证用户
- **描述**：获取当前登录用户的详细信息

**请求参数：** 无

**响应示例：**
```json
{
  "id": 1,
  "uuid": "660e8400-e29b-41d4-a716-446655440001",
  "username": "admin",
  "email": "admin@example.com",
  "phone": "13800138000",
  "display_name": "管理员",
  "company_id": 1,
  "company_name": "总公司",
  "role": "platform_admin",
  "locale": "zh-CN",
  "timezone": "Asia/Shanghai",
  "is_active": true,
  "last_login": "2026-03-12T10:00:00",
  "last_login_ip": "192.168.1.100",
  "created_at": "2026-01-01T00:00:00"
}
```

**响应字段说明：**

| 字段 | 类型 | 说明 |
|------|------|------|
| id | integer | 用户 ID |
| uuid | string | 用户 UUID |
| username | string | 用户名 |
| email | string | 邮箱 |
| phone | string | 手机号 |
| display_name | string | 显示名称 |
| company_id | integer | 所属公司 ID |
| company_name | string | 所属公司名称 |
| role | string | 角色（platform_admin, admin, company_admin 等） |
| locale | string | 语言环境 |
| timezone | string | 时区 |
| is_active | boolean | 账号状态（true=正常，false=禁用） |
| last_login | datetime | 最后登录时间 |
| last_login_ip | string | 最后登录 IP |
| created_at | datetime | 注册时间 |

---

### PUT /api/v1/users/me
- **权限**：已认证用户
- **描述**：更新当前用户信息（只能更新部分字段）

**请求体：**
```json
{
  "display_name": "新显示名称",
  "phone": "13900139000",
  "locale": "zh-CN",
  "timezone": "Asia/Shanghai"
}
```

**请求字段说明：**

| 字段 | 必填 | 说明 |
|------|------|------|
| display_name | 否 | 显示名称 |
| phone | 否 | 手机号 |
| locale | 否 | 语言环境 |
| timezone | 否 | 时区 |

**响应示例：** 同 GET /api/v1/users/me

## 头像上传与删除

后端定义见 [user_profile.py](../backend/app/api/user_profile.py) 的 `update_avatar` / `upload_avatar` / `delete_avatar`。

### PUT /api/v1/users/me/avatar
- **权限**：已认证用户
- **描述**：直接设置头像 URL（不上传文件）

**请求体：**
```json
{ "avatar": "https://cdn.example.com/avatars/xxx.jpg" }
```

### POST /api/v1/users/me/avatar
- **权限**：已认证用户
- **描述**：上传头像图片文件，由后端统一保存到 `uploads/avatars/`
- **限制**：JPEG / PNG / GIF / WebP；单文件 ≤ 5 MB

**请求**：`multipart/form-data`，字段名 `file`

**响应示例：**
```json
{
  "success": true,
  "avatar_url": "/api/v1/upload/<file_uuid>",
  "file_uuid": "...",
  "message": "头像上传成功"
}
```

### DELETE /api/v1/users/me/avatar
- **权限**：已认证用户
- **描述**：删除当前用户头像（同步清除文件记录与磁盘文件）

## 修改密码

### POST /api/v1/users/me/change-password
- **权限**：已认证用户
- **描述**：修改当前用户密码

**请求体：**
```json
{
  "old_password": "当前密码",
  "new_password": "新密码"
}
```

**请求字段说明：**

| 字段 | 必填 | 说明 |
|------|------|------|
| old_password | 是 | 当前密码 |
| new_password | 是 | 新密码（至少 6 位） |

**响应示例：**
```json
{
  "success": true,
  "message": "密码修改成功，请重新登录"
}
```

**错误响应：**
```json
{
  "detail": "当前密码错误"
}
```

或

```json
{
  "detail": "新密码长度不能少于 6 位"
}
```

## 登录日志

### GET /api/v1/users/me/login-logs
- **权限**：已认证用户
- **描述**：获取当前用户的登录日志列表

**查询参数：**

| 参数 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| page | integer | 否 | 1 | 页码 |
| page_size | integer | 否 | 10 | 每页数量（最大 100） |

**响应示例：**
```json
{
  "total": 50,
  "page": 1,
  "page_size": 10,
  "items": [
    {
      "id": 1,
      "login_time": "2026-03-12T10:00:00",
      "ip_address": "192.168.1.100",
      "location": "广东省深圳市",
      "device": "Chrome 浏览器 on Windows 10",
      "success": true,
      "failure_reason": null
    },
    {
      "id": 2,
      "login_time": "2026-03-11T15:30:00",
      "ip_address": "192.168.1.101",
      "location": "广东省广州市",
      "device": "Safari 浏览器 on iPhone",
      "success": false,
      "failure_reason": "密码错误"
    }
  ]
}
```

**响应字段说明：**

| 字段 | 类型 | 说明 |
|------|------|------|
| id | integer | 日志 ID |
| login_time | datetime | 登录时间 |
| ip_address | string | IP 地址 |
| location | string | 登录地点（基于 IP 地理位置） |
| device | string | 设备信息（浏览器 + 操作系统） |
| success | boolean | 是否成功 |
| failure_reason | string | 失败原因（如果失败） |

## 前端调用示例

### 1. 获取用户信息

```javascript
// api/user.js
import request from '@/utils/request'

export function getCurrentUser() {
  return request({
    url: '/api/v1/users/me',
    method: 'get'
  })
}

// 组件中使用
import { getCurrentUser } from '@/api/user'

export default {
  methods: {
    async loadUserInfo() {
      try {
        const response = await getCurrentUser()
        this.userInfo = response
        // 保存到 localStorage
        localStorage.setItem('user', JSON.stringify(response))
      } catch (error) {
        console.error('获取用户信息失败:', error)
      }
    }
  }
}
```

### 2. 修改密码

```javascript
// api/user.js
import request from '@/utils/request'

export function updatePassword(data) {
  return request({
    url: '/api/v1/users/me/change-password',
    method: 'post',
    data
  })
}

// 组件中使用
import { updatePassword } from '@/api/user'

export default {
  methods: {
    async handleChangePassword() {
      try {
        await updatePassword({
          old_password: this.passwordForm.old_password,
          new_password: this.passwordForm.new_password
        })

        this.$message.success('密码修改成功，请重新登录')
        
        // 退出登录
        setTimeout(() => {
          localStorage.removeItem('token')
          localStorage.removeItem('user')
          this.$router.push('/login')
        }, 1500)
      } catch (error) {
        this.$message.error(error.response?.data?.detail || '修改密码失败')
      }
    }
  }
}
```

### 3. 获取登录日志

```javascript
// api/user.js
import request from '@/utils/request'

export function fetchLoginLogs(params) {
  return request({
    url: '/api/v1/users/me/login-logs',
    method: 'get',
    params
  })
}

// 组件中使用
import { fetchLoginLogs } from '@/api/user'

export default {
  data() {
    return {
      loginLogList: [],
      loginLogTotal: 0,
      loginLogPage: 1,
      loginLogPageSize: 10
    }
  },
  methods: {
    async fetchLoginLogs() {
      try {
        const response = await fetchLoginLogs({
          page: this.loginLogPage,
          page_size: this.loginLogPageSize
        })

        this.loginLogList = response.items || []
        this.loginLogTotal = response.total || 0
      } catch (error) {
        console.error('获取登录日志失败:', error)
        this.loginLogList = []
      }
    },
    
    handleLoginLogPageChange(page) {
      this.loginLogPage = page
      this.fetchLoginLogs()
    }
  }
}
```

## 注意事项

1. **Token 认证**：所有接口都需要在请求头中携带 JWT Token
   ```
   Authorization: Bearer {token}
   ```

2. **密码安全**：
   - 密码长度至少 6 位
   - 建议使用强密码（大小写字母 + 数字 + 特殊字符）
   - 密码修改成功后需要重新登录

3. **登录日志**：
   - 登录日志在用户登录时自动记录
   - 包括成功和失败的登录尝试
   - 地理位置基于 IP 地址解析

4. **数据缓存**：
   - 用户信息建议缓存到 localStorage
   - 登录日志建议设置合理的刷新间隔

5. **请求示例中的 `request`**：原示例使用了 `@/utils/request`，本项目实际已统一收敛到 [src/api/http.js](src/api/http.js) 的 axios 实例。新代码请直接 `import http from '@/api/http'`，调用方式 `http.get('/users/me')` 即可（baseURL 已含 `/api/v1`）。
