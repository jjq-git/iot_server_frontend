# 前端需求记录

> 最后更新：2026-09-23

本页记录 Web 前端（`ito_admin_vue2`）的功能与交互需求，区分待确认和已确认事项。完成后勾选 `[x]`，保留条目。

> 迁入说明：本文自 `docs.podsc.com` 的内部评审目录迁入（该目录随数据模型评审完成后清理），需求本体归前端仓库维护。App 端同类需求见 app 仓库的 `apk-requirements.md`。

## 需求清单

- [ ] 多公司切换（已确认）
    - 使用场景：同一个用户属于多个公司或家庭，需要切换当前使用的组织。
    - 期望行为：提供组织切换入口，显示当前组织及用户可进入的组织列表；切换后同步更新组织名称、静音舱列表、业务数据和操作权限。家庭组织按家庭称呼展示。
    - 配合事项：使用用户的有效成员关系和组织切换接口更新登录上下文；切换后清理上一组织的页面状态与缓存，按新组织权限重新加载数据。
    - 现有覆盖：信息架构与页面见 [docs/ui/业务流程图.md](ui/业务流程图.md)、[docs/ui/company-users.md](ui/company-users.md)；后端组织切换契约见 [01_authorization.md](../../iot_server_backend/docs/数据模型/01_authorization.md)（`POST /api/v1/auth/switch-organization`）。
