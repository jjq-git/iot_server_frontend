## 维护规则

- 通用 UI 规范与视觉稿放在 `docs/ui/`；业务设计、规划和方案类文档放在 `docs/`，不要混进 `src/views/`、`src/components/` 等代码目录
- 文档顶部必须含"最后更新"日期
- 较长文档(>100 行)必须含 TOC 目录
- 后端契约相关内容请回链 `backend/docs/`,不要在本目录复制粘贴
