## WebSocket 协议

`MQTT 消息流` 走 `ws(s)://<host>/api/v1/ws/debug/mqtt-stream?token=<jwt>&host_uuid=<uuid>&topic=<filter>`。

推送消息结构(后端约定):

```json
{
  "type": "mqtt",
  "ts": 1730000000.123,
  "host_uuid": "abcd...",
  "topic": "iot/dev/.../up",
  "payload": {...},
  "qos": 0
}
```

心跳:前端每 30s 发 `{"type":"ping"}`,后端回 `{"type":"pong"}`。

**重连策略**（参考 [后端 WebSocket 文档](../../iot_server_backend/docs/api/WebSocket.md)）：指数退避，初始 1s，每次翻倍，上限 30s，任意 `onopen` 后归零。封装见 [src/api/debug/mqtt_stream.js](../src/api/debug/mqtt_stream.js) 的 `createMqttStream()`。

### 设备控制台
路由 `/debug/device-control`,视图 [src/views/debug/DeviceControl.vue](../src/views/debug/DeviceControl.vue)。

commit `40f05a1` 大重写:**控件不再写死成"灯/风扇/冷光"三滑块**,而是按节点的 OD 规范(unit_models OD spec)动态渲染。

- **三级 dropdown**:主机 → 节点(host 自身或 `node:<can_id>`)→ 规范版本
- **按 group 分卡**:每个卡片头标注 `group_name + group_index`,卡片体逐行 entry 渲染
- **字段类型 → 控件**:

  | OD entry 类型 | 渲染控件 |
  |---|---|
  | BOOL | `b-form-checkbox switch`(显示 ON/OFF) |
  | 数值 + 有 min/max(range) | `b-form-input type="range"` 滑杆 + 数值附加 |
  | 数值(无范围) | `b-form-input type="number"` |
  | 枚举 | `b-form-select` |
  | 字符串 | `b-form-input type="text"` |
  | DOMAIN / 兜底 | `b-form-textarea`(JSON,提交前 parse) |

- **每行独立"下发"按钮**:逐字段 `POST /control`(`{attr_code, value}`)。这避免一次提交多字段时部分失败难定位
- **维护命令卡片**:NMT(start / stop / reset)、软重启、紧急停止 → `POST /maintenance`，危险操作经统一 `$uiConfirm` 服务二次确认
- **高级折叠**:展开后允许直接填 `raw attr_code` + JSON `value` 直发,绕过 OD 规范(用于规范没覆盖到的字段或临时调试)

### MQTT 消息流
路由 `/debug/mqtt-stream`,视图 [src/views/debug/MqttStream.vue](../src/views/debug/MqttStream.vue)。

该页面可接收跨租户原始 MQTT 主题和 payload，即使选择具体主机也不把浏览器端过滤视为安全边界，
因此页面和实时 WebSocket 均仅允许 `platform_admin`。租户 A/M 的 scope 内排障应使用设备日志、EMCY、
OD、OTA 或后端提供的主机 scope 化快照接口。

本期改动(commits `77da198` / `778e234` / `70bf955` / `7e859be`):
- **默认未选主机不订阅**(commit `7e859be`):`hostFilter` 默认 `''` 表示**未选主机**,此时不连 WebSocket、表格强制为空、徽章显示"未订阅"、重连/暂停按钮禁用、empty 文案显示"请先选择主机"。修复"顶级菜单点进来直接被全局消息刷屏"的 bug
- **`__all__` 哨兵作为显式"全部主机"**:下拉里第二项是"全部主机"(value=`__all__`),用户主动选才订阅全局流;具体 host_uuid 走精准过滤
- **WS 生命周期**:`watch hostFilter` 控制——`'' → 任何值` 触发 connect,`任何值 → ''` 主动 close 并重置 connected
- **主机下拉源**:进入页面 `fetchHosts({ page_size: 100 })`(对齐后端 `le=100` 上限)拉真实主机列表,并合并已收到 messages 里的 `host_uuid` 兜底
- **心跳帧自动识别**:把同一设备相邻两条 `status` 帧的 9 个业务字段(在线/NMT 状态/传感器主值等)逐一对比,**全部相同**则标记 `kind=heartbeat`
- **默认隐藏心跳帧**:顶部 toggle 按钮"隐藏心跳帧 (已开启)"切换可见性;但若用户在 kind 过滤里主动选了"心跳"则不再隐藏(优先级更高)
- **摘要中文化**:`在线 / 离线 / NMT <state> / N 行日志 / N 条 OD / OTA N% / 固件 vX.Y.Z`,关键值用括号附原始 `key=value`
- **串口日志摘要**:取 `data.lines[0]`,直接展示首行真实内容(`[级别 TAG] message`),前端不再要求点击展开
- **payload 默认折叠**:每行一个"展开"按钮,展开后才显示完整 JSON;额外有"展开所有 payload"全局开关
- **kind 过滤**:`status / od_dump / heartbeat / log` 等下拉
- **sticky 表头修复**(commit `778e234`):long-list 滚动时表头不再消失
- **i18n key**:8 种语言补 `empty_no_host` / `filter.host_placeholder` / `status.idle`(zh-CN/zh-TW/en/de/ko/fr/ja/es)

## 设计约束

- 不允许直接 `import axios`,所有请求经 [src/api/http.js](../src/api/http.js)
- 不修改已有 `.vue` 模板/样式(memory `feedback_iot_server_no_style_change`)。本次主题 P1 重构属于"全局 CSS 架构升级",已与用户对齐,详见 [深色主题移植.md](ui/深色主题移植.md)
- WebSocket 必须实现指数退避重连 + 心跳 + 组件销毁 close
- 凭证密码:前端展示一次后立即清除内存,不持久化
- 调试 group 任何写操作(控制/重置/吊销)前后端都必须记审计日志
- 设备控制台动态控件:OD spec 加载失败时,展示明显的 `specWarning` 文案,**绝不**直接发空命令
