## 总览

整个项目接入了 **深色 / 浅色** 两态主题切换(commit `936f107` 移除了原 auto 第三态,与 ota_manager 原版对齐):

- 用户在 **Topbar 顶栏右侧** 点亮度滑杆 + 月亮/太阳图标 → 切换 light / dark
- localStorage 持久化,**跨标签页同步**(同 origin)
- **防闪白**:Vue 实例化前同步把 `data-theme` 写到 `<html>`,刷新不会先白后黑
- 仅登录页用右下角 floating fab(因 Topbar 不挂载)

## 三层架构

```
┌──────────────────────────────────────────────────────────────────┐
│  src/assets/styles/_tokens.scss          (1) SCSS 变量,纯静态  │
│  $color-bg-page-light / $color-bg-page-dark / ... 138 浅 + 52 深 │
│         │ @use                                                    │
│         ▼                                                          │
│  src/assets/styles/_theme-vars.scss      (2) SCSS → CSS 变量      │
│  :root            { --color-bg-page: $color-bg-page-light; }      │
│  [data-theme=dark]{ --color-bg-page: $color-bg-page-dark;  }      │
│  共 ~75 对语义 CSS 变量                                          │
│         │                                                          │
│         ▼                                                          │
│  src/assets/styles/dark-theme.scss       (3) 兼容 alias + 组件   │
│  --tt-bg → var(--color-bg-page) (旧代码不破)                     │
│  .tt-fab / .tt-panel 等主题切换组件自身样式                       │
│         │                                                          │
│         ▼                                                          │
│  src/assets/styles/_bootstrap-theme.scss (4) BootstrapVue 暗色   │
│  [data-theme="dark"] .card / .table / .modal / ... 16 组覆盖     │
│         │                                                          │
│         ▼                                                          │
│  src/assets/styles/index.scss            入口,@use 上面四层      │
└──────────────────────────────────────────────────────────────────┘
                          │
                          ▼
        各 .vue 直接 background: var(--color-bg-card);
        主题切换自动跟,**不用写 [data-theme="dark"] .xxx { ... }**
```

### 1. _tokens.scss — 设计令牌(SCSS 变量)

[src/assets/styles/_tokens.scss](../../../src/assets/styles/_tokens.scss),纯 SCSS,**不输出任何 CSS**,只供 _theme-vars 引用。

包含浅 + 深两套调色板:**138 个浅色变量 + 52 个深色变量**(深色多数复用浅色,只 override 关键颜色),按语义命名:

```scss
// 背景
$color-bg-page-light: #f5f7fa;
$color-bg-page-dark:  #1e1e1e;
$color-bg-card-light: #ffffff;
$color-bg-card-dark:  #2d2d2d;

// 文字
$color-text-light:    #2c3e50;
$color-text-dark:     #e0e0e0;

// 边框 / 阴影 / 状态色 / 滚动条 / 主色 ...
```

### 2. _theme-vars.scss — SCSS → CSS 变量映射

[src/assets/styles/_theme-vars.scss](../../../src/assets/styles/_theme-vars.scss),把 SCSS 变量暴露成 CSS 变量,**浅色写在 `:root`,深色写在 `[data-theme="dark"]`**,共 **~75 对**(150 行 CSS 变量声明)。

```scss
@use "tokens" as *;

:root {
  --color-bg-page: #{$color-bg-page-light};
  --color-bg-card: #{$color-bg-card-light};
  --color-text:    #{$color-text-light};
  /* ... 75 行 ... */
}

[data-theme="dark"] {
  --color-bg-page: #{$color-bg-page-dark};
  --color-bg-card: #{$color-bg-card-dark};
  --color-text:    #{$color-text-dark};
  /* ... 75 行 ... */
}
```

**`.vue` 里只引用 `var(--color-xxx)` 就够了**,主题切换自动生效。

### 3. dark-theme.scss — 兼容层 + 组件样式

[src/assets/styles/dark-theme.scss](../../../src/assets/styles/dark-theme.scss):

- **`--tt-*` alias 兼容层**:旧代码写的 `var(--tt-bg)` `var(--tt-text)` 全部 alias 到新的 `var(--color-*)`,P2/P3 渐进迁移期不立刻坏(commit `84f1dac` 引入)
- **ThemeToggle 组件自身样式**:`.tt-fab` / `.tt-panel` / `.tt-controls--floating` / `.tt-mode-btn` 等
- **少量页面级全局兜底**(`.od-manager` / `[class*="mqtt-"]` 等):极个别还没迁完的写死色值,这里统一兜底

### 4. _bootstrap-theme.scss — Bootstrap 暗色覆盖

[src/assets/styles/_bootstrap-theme.scss](../../../src/assets/styles/_bootstrap-theme.scss),共 **16 组** BootstrapVue 类暗色覆盖:

| 类 | 覆盖 |
|---|---|
| `.card / .card-header / .card-footer` | bg + border |
| `.table / thead / tbody / .table-hover` | bg + border + hover |
| `.modal-content / .modal-header / .modal-footer` | bg + border |
| `.dropdown-menu / .dropdown-item` | bg + hover |
| `.form-control / .custom-select` | bg + border + focus |
| `.alert-* / .badge-light` | 暗色映射 |
| `.list-group-item` | bg + border |
| `.pagination .page-link` | bg + border |
| `.toast` | bg |
| `.nav-tabs` | border |
| `.btn-secondary / .btn-light` | bg + border + hover |
| `.b-table-sticky-header` | thead bg |
| `pre / code` | bg |
| 滚动条 | thumb / track |
| `hr` | border |

**保守对接策略**:不重写 BS 的 SCSS 变量(那会牵动整套色板),只在 `[data-theme="dark"]` 选择器下覆盖 BS 类的 `background-color / border-color / color`。

## 模式与状态

`<html>` 标签上挂 `data-theme="light|dark"`,JS / CSS 都可读:

```js
// 取
document.documentElement.getAttribute('data-theme')

// CSS 选择器
[data-theme="dark"] .my-card { ... }   // 但不推荐,优先用 var(--color-*)
```

localStorage key:

| key | 值 |
|---|---|
| `iot_admin_mode` | `light \| dark`(用户选的 mode,不再有 auto) |
| `iot_admin_theme` | `light \| dark`(实际生效,兼容用) |
| `iot_admin_brightness_light` | 30~100 |
| `iot_admin_brightness_dark` | 30~100 |

## 添加新颜色流程

**禁止在 .vue 直接写新 hex**,所有新颜色沿这条链扩展:

1. 在 [_tokens.scss](../../../src/assets/styles/_tokens.scss) 加 SCSS 变量,**浅+深各一对**:

   ```scss
   $color-bg-special-light: #abcdef;
   $color-bg-special-dark:  #112233;
   ```

2. 在 [_theme-vars.scss](../../../src/assets/styles/_theme-vars.scss) 暴露 CSS 变量,在 `:root` 与 `[data-theme="dark"]` 各加一行:

   ```scss
   :root            { --color-bg-special: #{$color-bg-special-light}; }
   [data-theme="dark"] { --color-bg-special: #{$color-bg-special-dark}; }
   ```

3. .vue / 子 SCSS 内部引用即可:

   ```scss
   .my-component {
     background: var(--color-bg-special);
   }
   ```

**禁止做的事**:

- 在 .vue 里写 `background: #abcdef;`(stylelint 会警告)
- 在 .vue 里写 `[data-theme="dark"] .xxx { ... }`(改 _theme-vars 而不是改组件)
- 直接修改 BootstrapVue SCSS 变量(只在 _bootstrap-theme 加选择器覆盖)

## 与原版差异

原版 [aliyun/web_components/theme_toggle](../../../../../aliyun/web_components/theme_toggle/) 是 Flask + Jinja2 macro 形态,本项目按 Vue 等价复刻:

| 能力 | 原版 | 本项目 |
|---|---|---|
| 模式 | light / dark 二态 | light / dark 二态(commit `936f107` 对齐,移除 auto) |
| Topbar 内联挂载 | 由宿主放置 | 挂在 [Topbar.vue](../../../src/components/Topbar.vue) 右侧 |
| floating fab | 无 | 仅登录页用 |
| 跨 tab 同步 | 有 | 保留 |
| 防闪白 | head 内同步脚本 | `applyThemeASAP()` Vue 启动前同步 |
| Tailwind 类映射 | 有 | 改为 BootstrapVue 类映射(_bootstrap-theme.scss) |
| design tokens 三层架构 | 无 | **新增**,根治写死 hex |
| stylelint 守门 | 无 | **新增** |
