# 全页面交互审计（2026-07-30）

> 最后更新：2026-07-30

## 审计范围

- 前端：86 条路由、50 个 Vue 页面、324 个点击绑定、26 个表单提交绑定。
- 接口：静态核对 209 处 HTTP 调用声明与后端 OpenAPI 路由。
- 后端：数据库迁移、设备/型号/绑定/控制/文件/固件/位置/监控/调试接口。
- 运行验证：前端 ESLint、生产构建、后端 pytest、HTTP/WS 端到端冒烟、真实数据库增删改查。

## 已确认并修复

1. 主机详情复制密钥在无 `navigator.clipboard` 的 HTTP/非安全上下文中抛异常；已增加安全降级复制实现。
2. 主机节点绑定弹窗原先使用假节点和延时假保存；现已接入创建、删除、替换、CAN ID 更新接口。
3. 系统监控页原先展示随机数据；现已接入真实数据库、MQTT、调度器、CPU、内存、磁盘和连接池状态。
4. 图表路由原先使用随机数据并存在定时器泄漏；已统一到真实仪表盘。
5. 调试凭证在 SQLite 下因 BIGINT 主键不能自动生成而返回 500；已修正模型和迁移。
6. 固件下载调用不存在的旧接口；已改为短期签名 URL，并实测下载 70,637 字节成功。
7. 位置删除调用不存在的接口；已补后端删除接口和子位置/已绑定设备保护。
8. 位置页已有编辑、删除逻辑但没有渲染入口；已按角色补齐入口。
9. 位置备注会被后端静默丢弃；已补模型、Schema、迁移和回归测试。
10. 位置编辑读取了错误的 GPS 字段，且经纬度为 0 时会被当成无坐标；前后端均已修复。
11. 三处 WebSocket 把 JWT 放入 URL；已迁移到 `Sec-WebSocket-Protocol`，并移除写死的局域网地址。
12. 系统监控的时间范围选择器没有任何业务效果；已替换为真正执行请求的刷新操作。
13. OTA 固件、OTA 任务和操作日志路由原先落到占位页；已重定向到现有真实功能页。
14. 文件、用户、位置、型号等页面的多处空数据弹窗、吞错、空引用、弹窗阻断和外链安全问题已修复。

## 验证结果

- 前端 ESLint：通过。
- 前端生产构建：通过；仅有包体积和 Browserslist 数据过期警告。
- 后端重点回归：28/28 通过。
- 后端规范测试：116 通过，3 失败；失败均因外置图标库 `platforms/icons` 未提供。
- HTTP/WS 端到端冒烟：36 通过，0 失败，2 跳过；跳过项为本机未启用的 EMQX 鉴权/ACL。
- 系统监控三个接口：HTTP 200，返回真实 Windows CPU/内存/磁盘和服务状态。
- 位置备注/GPS：真实数据库创建、修改、读取、删除通过。
- 固件签名下载：HTTP 200，二进制读取成功。

## 尚不能标记为“完全实机通过”的项目

1. 当前 Browser 插件包缺少其规定的 `scripts/browser-client.mjs`，因此无法执行逐页真实点击、键盘输入、焦点和浏览器控制台自动化。静态审计、构建和 API 联调不能冒充这部分浏览器实测。
2. EMQX 在当前环境未启用，真实设备上下线、MQTT ACL 和 OTA 到设备的最终闭环仍需实际 broker/设备。
3. 后端依赖的共享图标库未出现在工作区，也未配置 `ICON_LIBRARY_ROOT`，对应 3 个测试无法运行成功。
4. 本地 `.env` 仍使用默认 JWT 密钥；只适合纯本地开发，对外部署前必须改为至少 32 字符的强随机密钥。
5. 仍有 12 条文档/配置说明路由使用 `DocPage` 文档壳页面；它们不是业务交互页，但目前也不会直接渲染文档正文。

## 结论

已完成代码级全路由审计、前后端契约核对和可运行环境中的端到端验证。已发现的业务交互断点均已修复；剩余项属于缺失的浏览器自动化运行文件、外部服务/设备、外置图标资源和部署配置，不能被声明为已实机验证。
